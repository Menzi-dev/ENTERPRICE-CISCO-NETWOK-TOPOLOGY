# ENTERPRICE-CISCO-NETWOK-TOPOLOGY
A scalable enterprise campus network simulation demonstrating real-world network design, routing, switching, wireless deployment, IP addressing, and security principles.

## Project Highlights

- Cisco 3-Tier Hierarchical Architecture (Core, Distribution & Access)
- 11 isolated network segments
- 60+ simulated devices
- VLAN implementation and Inter-VLAN routing
- OSPF dynamic routing
- WAN connectivity between main and remote campus
- WLC-managed and standalone wireless networks
- DHCP, DNS, and centralized authentication services
- Enterprise network security principles

---

## Network Architecture

### Core Layer
- Multilayer switching
- Inter-VLAN routing
- OSPF routing
- Server and WAN connectivity

### Distribution & Access Layer
- Cisco 2960 switches
- VLAN segmentation
- Trunk connections
- End-user connectivity
